---
title: Agent Terminal (removed)
description: The Agent terminal page is no longer part of the Command Center.
---

The **Agent** page has been removed from the Command Center. Old `/agent` links now open **Stats**.

Run your coding agent in its own app or terminal instead (Cursor, Claude Code, Codex, opencode, Gemini CLI, …). To wire ax into it, open **Settings → IDEs & agents** in the Command Center and click **Connect**, or run:

```bash
ax install
```

See [Command Center](/guides/command-center/) for the current pages and sidebar.
